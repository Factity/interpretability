1. Correlated features collapse; anticorrelated features repel

For each designated pair we track the cosine similarity between the two features' weight vectors. Correlated pairs (orange) are pushed toward cos = +1 — they end up pointing the same direction, effectively sharing one dimension between two features that are never asked to be distinguished when only one is 'on', since they never occur alone. Anticorrelated pairs (blue) are pushed toward cos = −1 — the classic antipodal-pair trick, which works because these features are non-negative and ReLU clips the resulting negative interference to zero, and it's especially effective here because the two features are guaranteed to never co-occur. The dashed gray line shows that plain independent features also drift toward negative cosine with *some* partner as sparsity grows — but only to about −0.6 to −0.9, and with a different (essentially random) partner in every run, since there's no guarantee against occasional co-occurrence.
